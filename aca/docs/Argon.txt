### 1. [Associative Context Activation (ACA) - Architectural Specification](https://docs.google.com/document/d/1gW8P3-yrk-QZeDf-EJJsN4aipqDlSX024XBY7JLrWwc/edit?usp=drivesdk&ouid=114824787537335847480)

This document covers the full **ACA** cognitive graph and **Jev** decision engine architecture:

* **Core Thesis:** Shifting from stateless search (`question → search → top result → answer`) to associative activation that converges on the smallest, strongest connected context field.


* **Cognitive Store & Synapse Graph:** Storing typed engineering objects (memories, files, commits, decisions, hypotheses, tests) connected by explicit relational links with provenance chains and calibrated trust weights.


* **Spreading Activation, Competition, & Inhibition:** Event-driven seed detection, hop-attenuated spreading across the graph, active suppression of stale or low-relevance nodes, and context convergence under strict budgets (balancing exploitation vs. exploration).


* **Working Brain & Parallel Jev Neurons:** Serializing active state for parallel **Jev** evaluations (`Noul`, `Choice`, and `Score`), mapping probabilities across firing thresholds, and propagating strong decisions back into the graph.


* **Memory Tiers, Agent Swarms, & Instrumentation:** Managing Episodic, Semantic, and Procedural memory alongside Hypothesis/Contradiction networks, event-driven agent swarms on a Shared Cognitive Fabric, and live observability (`Firing Brain`, `Brain Inspector`, and `Context Replay`).

### 2. [The Firing System - Architectural Specification](https://docs.google.com/document/d/1ngADGX2med_JQD9PFOzV2GS5qNnHOu28KBGnGTAJfj0/edit?usp=drivesdk&ouid=114824787537335847480)

This document covers **The Firing System** as a pure, stateful dynamical memory model:

* **Core Thesis:** Treating relevance as a continuous state that each piece of memory is already in across a work trajectory, rather than recomputing similarity from scratch on every turn.


* **Memory Primitives:** Schema-free prose **Fragments** holding persistent activation levels and directed weighted links, local **Emergent Regions**, and the append-only raw log reserved for ground-truth recovery.


* **The Four-Stage Firing Pass:**
* **`INJECT`:** Direct input matching that raises fragment activation.


* **`FIRE`:** Threshold crossing, neighbor spreading, refractory periods, co-firing link potentiation, and continuous activation/weight decay.


* **`ADMIT`:** Populating the bounded Working Set from the highest-activation fired fragments.


* **`COMPOSE`:** Synthesizing admitted fragments into a temporary **Canonicalized Atomic Narrative (CAN)** alongside the last few raw turns while enforcing the invariant that reconstruction never becomes assertion.




* **Recurrent Settling & Surprise-Gated Encoding:** Feeding intermediate reasoning back as a low-gain self-cue until the lit set stabilizes ("think until it settles"), and writing new canonical fragments *only* when outcomes violate what the lit set predicted.
