Install

Reidcc runs on Windows 10 and 11. The installer is per user: no admin rights, nothing in Program Files.

Before you start

  • Claude Code, installed and signed in once. Reidcc launches it; it doesn't replace it.
  • Codex, only if you want Codex profiles.
  • Windows Terminal, only if you open sessions there instead of in Reidcc's own window.

Run the installer

  1. Download Reidcc_0.1.1_x64-setup.exe from the latest release.
  2. Run it. Windows SmartScreen may ask once, since the installer isn't signed yet.
  3. Reidcc opens on the launcher. Pick a folder, then open gate.
note · unsignedSmartScreen shows "Windows protected your PC". Choose More info → Run anyway. The checksum for each release is on its release page.
