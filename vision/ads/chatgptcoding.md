## Title

I built a Windows launcher to run Claude Code and Codex side by side with saved profiles and live usage

## Body

I use both Claude Code and Codex depending on the task. Each setup needs its own model, login, and settings, and I got tired of editing config files every time I switched.

I built this launcher, **Reidcc**, to make switching one click. I am a self-taught solo dev, and I built it mostly with Claude Code from my own specs.

Here is what it does:

- Saves a profile for each setup: engine (Claude Code or Codex), model, sign-in, persona, tools, and MCP config.
- Opens each session in its own window. Claude sessions show live context and usage-limit percentage.
- Snaps windows side by side and saves the layout as a rig, so one click opens a Claude pane next to a Codex pane.
- Includes a terminal UI. Typing `/reid` inside a session brings you back to switch profiles and resume.

It runs on Windows, uses your own CLIs and logins, and is free for personal use.

Source: https://github.com/AIden6464-AI/reidcc
