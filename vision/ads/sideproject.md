## Title

I spent my evenings building a Windows launcher for Claude Code and Codex, with a gate that opens for each session

## Body

I'm a self-taught solo dev. I run Claude Code and lately Codex all day with different setups. Switching between them meant dealing with config files and flags every time.

I built this to replace that workflow. It's called **Reidcc**. You pick a folder, pick a profile, and press **open gate**. An animated gate opens into your session.

Each profile holds a model, a login, a persona, tools, and memory. Sessions open in their own windows with live context and usage limits. You can snap them together and save the layout. There is also a terminal version.

The most enjoyable part was the design. It uses dark emerald-and-bronze art, backed by a design doc for every color, motion, and word on screen. I write specs before anything gets built, and the app was built with Claude Code from those specs. Claude Code wrote most of the code while I handled direction, review, and testing.

It is free for personal use and Windows only for now.

Site: https://aiden6464-ai.github.io/reidcc/
