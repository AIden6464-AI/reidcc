## Title

Reidcc: a Windows launcher for Claude Code and Codex with profiles, live usage limits, and saved window layouts (Rust + Tauri)

## Body (if text is allowed alongside the link)

I built this Windows launcher for Claude Code and Codex, mostly with Claude Code. I'm a self-taught solo dev and wanted a straightforward way to run and organize multiple sessions on Windows.

Profiles hold your model, login, persona, tools, and memory. Each session opens in its own window with live context and usage limits, and you can snap and save window layouts. It is built with Rust and Tauri.

Free for personal use under the PolyForm Noncommercial license.

Link: https://github.com/AIden6464-AI/reidcc

If you run multiple Claude Code or Codex sessions on Windows, how are you managing your profiles and window layouts right now?
