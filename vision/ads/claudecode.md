## Body

I use Claude Code with a few different setups (models, logins, personas, MCP servers, and memory), often at the
same time. I built this to stop retyping flags every time I opened a session. It is a Windows launcher called
**Reidcc**, built mostly with Claude Code from my own specs.

Here is how it fits into my daily workflow:

- **Profiles.** A profile holds the model, sign-in, persona, tools, MCP config, and switches. One click opens
  Claude Code with that setup on the current folder.
- **`/reid` and resume.** Type `/reid` inside a session to drop back to the launcher. From there you can resume
  the same conversation under a different profile if you want to switch model or persona mid-task.
- **Rigs.** Snap session windows into a split layout and save it as a rig. Next time, the whole layout opens in
  one click, with each pane running its own profile and folder.
- **Context and limits in sight.** The bar on each session window shows context % and usage-limit %.

It runs on Windows, uses your own Claude Code, and is free for personal use.
