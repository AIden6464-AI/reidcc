# Sizes and the mini pod

The launcher has three sizes and the pod, so it can stay on screen while you work.

| Size | Key | What's on it |
|---|---|---|
| **main** | `Alt+1` | Everything: the profile list, the profile's fields, the folder, the command |
| **medium** | drag the window narrow | The form: the profile's fields in one column |
| **small** | `Alt+2` | The folder, the sessions that run, and combos |
| **the pod** | `Alt+3`, or drag the window small | A capsule with one slot per running session |

Resizing the window picks the layout that fits. **settings → default size** picks the size it opens at.

## Combos

On **small**, keys `1`–`9` are combos: that profile, then open gate on the current folder. One key to start a session.

## The pod

The pod is a small capsule with a slot for each running session. Double-click it, or press `Alt+1` / `Alt+2`, to unfold it again.

## Inside a session window

The launcher also opens inside a session window. Click **RC** on the session bar (or `Alt+2`) and it opens
beside the terminal; click again (or `Alt+1`) for full; again to close. The terminal keeps its size.
See [session windows](./session-windows#reidcc-in-the-window).
