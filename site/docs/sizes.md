# Sizes and the mini pod

The launcher folds to three sizes, so it can stay on screen while you work.

| Size | Key | What's on it |
|---|---|---|
| **full** | `Alt+1` | Everything: the profile list, the profile's fields, the folder, the command |
| **medium** | `Alt+2` | The folder, the sessions that run, and combos |
| **mini pod** | `Alt+3`, or drag the window small | A capsule with one slot per running session |

Resizing the window picks the layout that fits.

## Combos

On **medium**, keys `1`–`9` are combos: that profile, then open gate on the current folder. One key to start a session.

## The mini pod

The pod is a small capsule with a slot for each running session. Double-click it, or press `Alt+1` / `Alt+2`, to unfold it again.
