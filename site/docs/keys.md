# Keys

## The launcher

| Key | Does |
|---|---|
| `Enter` (on the profile list) | open gate |
| `Ctrl+Enter` | open gate, from anywhere |
| `Ctrl+O` | pick folder |
| `Ctrl+R` | resume the last Claude session |
| `Esc` | clear a message; close settings |
| `Alt+1` / `Alt+2` / `Alt+3` | full / medium / mini pod |
| `1`–`9` (medium size) | combo: that profile, then open gate |

## Session windows

## The terminal launcher

`reid` in a terminal opens the same launcher as a TUI:

```text
↵ open gate · r resume · e edit · n new · x delete · d default · w pick folder · m memory · 1–9 jump · q quit
```
