# Keys

## The launcher

| Key | Does |
|---|---|
| `Enter` (on the profile list) | open gate |
| `Ctrl+Enter` | open gate, from anywhere |
| `Ctrl+O` | pick folder |
| `Ctrl+R` | resume the last session (Claude or Codex) |
| `Esc` | clear a message; close settings |
| `Alt+1` / `Alt+2` / `Alt+3` | main / small / the pod. Drag the window narrow for medium |
| `1`–`9` (small size) | combo: that profile, then open gate |

## Session windows

| Key | Does |
|---|---|
| `Alt+2` | Reidcc beside the terminal (same as clicking **RC**) |
| `Alt+1` | Reidcc full |

The rest: [session windows](./session-windows#keys-in-the-window).

## The terminal launcher

`reid` in a terminal opens the same launcher as a TUI:

```text
↵ open gate · r resume · c chat · e edit · n new · x delete · d default · w pick folder · m memory · 1–9 jump · q quit
```

In its chat: `tab` picks the profile · `ctrl+r` read-only · `ctrl+t` open terminal · `ctrl+d` the diff · `ctrl+e` tune.
